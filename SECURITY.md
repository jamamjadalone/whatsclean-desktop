# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Privacy & Security Guarantee
WhatsClean Desktop is designed from the ground up as a **100% offline, zero-telemetry utility**:
- It never initiates outbound network connections.
- It never uploads telemetry, crash reports, or user chat data.
- Deletions are sent to the Windows Recycle Bin by default to guard against accidental data loss.

## Reporting a Vulnerability
If you discover a security vulnerability or bug that may risk user privacy or system integrity:
1. Please do **NOT** open a public issue.
2. Submit a private report via GitHub Security Advisories or email the maintainer directly.
3. We will respond within 48 hours to validate and resolve the issue.
